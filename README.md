# Smekal Registry Compare

**Free Windows registry comparison tool for comparing registry keys and values.**

Smekal Registry Compare is a Windows utility developed by **Smekal Solutions** to compare Windows Registry keys and values and identify differences between registry configurations.

## Features

- Compare Windows Registry keys and values
- Identify added, removed, and modified registry entries
- Simple Windows user interface
- Free for personal and commercial use
